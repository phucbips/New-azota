## 2025-05-19 - Global Theme Token Strategy
**Learning:** Significant UI overhauls ("Complete Interface Renewal") can be effectively delivered within "micro-UX" constraints by modifying global CSS tokens (`:root` variables) rather than refactoring individual components. This approach minimizes risk and maximizes impact.
**Action:** When asked for a "design system update" or "new look", first audit `globals.css` and `tailwind.config.js` to see if a token-based strategy suffices.
