## 2024-05-22 - [Lazy Loading Dashboards] **Learning:** Static imports of large role-based components (Dashboards) in the main entry point defeat the purpose of code-splitting, resulting in a monolithic bundle that downloads unused code for the current user role. **Action:** Always use `React.lazy` and `Suspense` for top-level route components or role-based containers to ensure users only download the code relevant to their permission level.
